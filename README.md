# Swipe Panel v1.0
Android 8.0+ / Kotlin / 黒×青の半透明オーバーレイ

## 機能
- 画面中央を始点に上下左右・斜め45°の8方向へスワイプ
- フローティングパネル（ドラッグで移動可能、中央×で閉じる）
- スワイプ距離10〜70%（画面短辺基準）、時間50〜1000ms
- インターネット権限なし。画面内容の取得・外部送信なし

## ビルド
1. Android Studioでこのフォルダを開く。
2. Gradle Syncが終わったら **Build > Build Bundle(s) / APK(s) > Build APK(s)**。
3. `app/build/outputs/apk/debug/app-debug.apk` を端末にインストール。
4. アプリで「他のアプリの上に表示」を許可し、ユーザー補助設定からSwipe Panelを有効化。
5. アプリに戻り「パネルを表示」。

## 注意
- Androidのユーザー補助ジェスチャーを使うため、端末や対象アプリによって動作しない場合があります。
- 方向は画面座標基準。斜めは縦横の移動量が等しい45度です。
- 画面中央は端末の物理画面座標基準で計算します。
- 本環境ではAndroid SDKがないためAPKのビルド・実機検証は未実施です。
